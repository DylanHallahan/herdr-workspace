# Personal project workspace

This workspace is for personal projects. It has no inherited projects, assignments, credentials or authority from another machine.

- Follow the current user's request and each repository's instructions.
- Work only on assigned personal repositories. Store checkouts in ~/Projects and isolated worktrees in ~/Projects/.worktrees.
- Deliver complete, reviewable changes and run checks appropriate to the change.
- Continue through actions already authorized by the user; ask only when a consequential choice or missing authority requires it.
- Do not publish, deploy, send messages or change shared services unless authorized by the current task.
- Keep credentials in the tools' own authentication stores, never in the vault.
- Use one writer per checkout. Delegate only when the user or applicable instructions authorize it.
- Do not infer new assignments from historical notes.
