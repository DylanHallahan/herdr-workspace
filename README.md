# Personal Herdr workspace

Public snapshot of the personal Herdr workspace instructions under `~/herdr`.

- `POLICY.md`: workspace scope, authorization and credential boundaries.
- `PLAYBOOK.md`: brief, implementation, review, verification and reporting workflow.
- `roles/`: lead, implementation lead, builder and reviewer responsibilities.
- `lead-agent/` and `implementation-lead/`: agent instruction loaders.
- `inbox-agent/`: RainCLI inbox role, Claude/Codex loaders and current local operational state.

This repository contains instructions and the existing resume helper, not the Herdr application source, vault contents, message queues, credentials or session transcripts. The resume helper reflects the owner's current local settings and disables Codex approval/sandbox prompts; review it before using it on another machine.

`~/herdr` remains the live workspace; this checkout is a versioned backup. Review changes before copying files back, and preserve any newer live instructions. Inbox STATE.md is a snapshot: verify current identity, pane and connector mappings before using them.
